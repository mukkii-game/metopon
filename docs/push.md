# METOPON PUSH（第三案）— 押して、そろえて、撃ち上げる

`push/index.html`。本編・BLAST とは別の試作で、アセットだけ共用している。

## 何が新しいか
盤面を**直接触って並べ替えない**。自機が外周を走り、**撃った弾でレーンを押す**。
シューティングの「狙って撃つ」がそのままパズルの入力になっている。

## 自機とレール
クォース風に画面の外周を走る。

- **底辺** … 左右に動く。撃つとその**列が上へ**1マス押される。
- **左端** … 底辺の左端まで行くとそのまま上下に動ける。撃つとその**行が右へ**。
- **右端** … 同じく上下。撃つとその**行が左へ**。

端から押し出されたマスは**反対側に戻ってくる**（ループ）。盤面は欠けず、
純粋な並べ替えになる。天井はボスなので、下向きの押しは無い。

## ためて、離して、押す
**押している間、弾がたまる。離すと1発出る。**
たまった段数がそのまま**押す距離**になる。

| 押している長さ | 段 | 押す距離 |
| --- | --- | --- |
| 軽くタップ | 1 | 1マス |
| 0.3秒 | 2 | 2マス |
| 0.6秒以上 | 3（MAX） | 3マス |

軽く連打すれば1マスずつ細かく、ためて離せば一度に3マス動かせる。
弾の威力も段数ぶんで、雑魚も一撃で抜けるようになる。

段数は自機の上の四角3つと、自機を包む光で出る。
押される距離は**レーンの矢印の本数**で出る。

（当初は「同じレーンに3発当てると1マス押せる／途中で別を撃つとリセット」に
していたが、分かりづらかったのでこの方式に変えた。）

## そろえて、タップして、撃ち上げる
同じ模様が縦か横に3つ以上そろうと、その塊の**輪郭が水色に光る**。
光っている所を**タップ**すると、その塊が盤面から浮き上がって発射準備に入り、
**1.8秒後**に上空のボスへ飛んでいく。跡は新しいマスで埋まる。

- ダメージは **マス数²÷2**。3マスで5、4マスで8、5マスで13。大きい塊ほど効く。
- **3.2秒以内**に次を当てるとコンボ。倍率はダメージとスコアの両方に乗る。
- 浮き上がっている間も下の盤面は動かせるので、続けて仕込める。

## 降りてくる雑魚
ボスが雑魚を落としてくる。**弾は雑魚にも当たる**ので、撃ち落とさないと
弾を食われてレーンに届かない。

雑魚が自機まで降りてくると体当たりされ、**0.9秒動けなくなり、
レーンが1つ勝手に押される**。積み上げた形が崩れるのが痛い。

## ウェーブ
ボスを倒すと次のウェーブ。

- 盤面は **5×5 → 6×6 → 7×7 → 8×8**（上限8）。見た目の大きさは一定で、マスが細かくなる。
- ボスは**装甲が増え、見た目も大きくなる**（装甲 32 + ウェーブ×22）。
- 雑魚は湧きが速くなり、大きい機体も出るようになる。

## 操作（バーチャルパッドは使わない）
- **指を置く／なぞる** … 自機がレール上の一番近い所へ回り込む。押している間はためる。
- **離す** … ためた段数の弾が1発出る。
- **光った塊をタップ** … 発射準備。押し出しにはならない。
- PCは ←→ 移動、Space/Z でためて離す、X で光っている塊を発射準備。

### 指で自機が隠れないように
画面の**左右と下に暗い帯**を置き、そこを指の置き場にしている。
レールは帯より内側（盤面のすぐ外）にあるので、帯に指を置くと
自機はその内側に立ち、指に隠れない。
帯を広く取った分だけ盤面は細くしてある。

## 音
効果音のほかに**BGM**（8bitのループ、約14秒）が鳴る。音ボタンで両方まとめて切れる。
撃ち上げの瞬間には専用の発射音を鳴らしている。

iPhone は着信スイッチが「消音」だと WebAudio ごと黙ってしまうので、
無音の `<audio>` を最初のタップで一度鳴らして再生扱いにし、消音でも鳴るようにしている。

## 仮の数値
盤面の見た目 240px 固定（指の帯は左右74px・下108px）。
チャージは0.3秒ごとに1段、最大3段。発射までの待ち 1.8秒。
コンボ窓 3.2秒。弾速 760px/秒。

## これから確かめること
チャージの段数（0.3秒刻み・最大3）が気持ちよいか。1マスずつ連打と3マスまとめ押しの使い分け。
ループの押し出しで狙った形を作れるか（8×8まで大きくなった時に破綻しないか）。
指の帯の広さは足りているか。雑魚の妨害の強さ。発射までの1.8秒の使い道。
