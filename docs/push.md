# XEMETOUS（第三案）— 押して、そろえて、撃ち上げる

`push/index.html`。本編・BLAST とは別の試作で、アセットだけ共用している。

**全4面。1面あたり2分のタイムアタック。** エジプト神話の神々を4体、
1体ずつ2分以内に倒していく。4体とも倒せばクリア（おめでとう）。

## 何が新しいか
盤面を**直接触って並べ替えない**。自機は盤面の下と左右を動き、**撃った弾でレーンを押す**。
シューティングの「狙って撃つ」がそのままパズルの入力になっている。

## 自機のエリア
**盤面の真下に、盤面とぴったり同じ5列ぶんの広場**（5×5）がある。
ここでは**上下左右どこへでも**動ける。左右にはこれまでどおり縦のレールがある。

- **下の広場** … 上下左右。撃つとその**列が上へ**1マス押される。
  上下に動いても押す列は変わらない。上下は雑魚へ寄るための動き。
- **左のレール** … 上下だけ。撃つとその**行が右へ**。
- **右のレール** … 上下だけ。撃つとその**行が左へ**。

端から押し出されたマスは**反対側に戻ってくる**（ループ）。盤面は欠けず、
純粋な並べ替えになる。天井はボスなので、下向きの押しは無い。

**下の広場では、自機は指のちょうど 56px 上に立つ。** 指を置いた所そのものではないので、
広場の中に指を置いても自機が隠れない。
**左右のレールでは上下のずらしは無い**（自機が横＝盤面寄りへずれるので、
上下までずらすと狙った行から1マス浮いてしまう）。

また、**自機そのもの（38px以内）を押した時は動かさない**。
その場で発射／長押しになる。なぞり始めれば、いつもどおり指の上へ持ち上がる。

## 移動と発射を分ける
**1回目のタップは移動だけ。** 今いるのと違うマスをタップすると、
自機はそこへ即座に回り込むが**弾は出ない**。

**同じマスをもう一度タップすると1発出る。**
押したままにすると弾がたまり、**離した時に**ためた分が出る。
たまった段数がそのまま**押す距離**になる。

なぞって移動した場合も撃たない（指を14px以上動かした時点で「移動」扱い）。
狙っていないレーンを暴発で押してしまう事故が起きない。

| 押している長さ | 段 | 押す距離 |
| --- | --- | --- |
| 軽くタップ | 1 | 1マス |
| 0.3秒 | 2 | 2マス |
| 0.6秒以上 | 3（MAX） | 3マス |

軽く連打すれば1マスずつ細かく、ためて離せば一度に3マス動かせる。
弾の威力も段数ぶんで、雑魚も一撃で抜けるようになる。

段数は自機の上の四角3つと、自機を包む光で出る。
押される距離は**レーンの矢印の本数**で出る。

（当初は「同じレーンに3発当てると1マス押せる／途中で別を撃つとリセット」に
していたが、分かりづらかったのでこの方式に変えた。）

## そろえて、タップして、撃ち上げる
同じ模様が縦か横に3つ以上そろうと、その塊の**輪郭が水色に光る**。
光っている所を**タップ**すると、その塊が盤面から浮き上がって発射準備に入り、
**1.8秒後**に上空のボスへ飛んでいく。跡は新しいマスで埋まる。

- ダメージは **マス数²÷2**。3マスで5、4マスで8、5マスで13。大きい塊ほど効く。
- **3.2秒以内**に次を当てるとコンボ。倍率はダメージとスコアの両方に乗る。
- 浮き上がっている間も下の盤面は動かせるので、続けて仕込める。

## 4×4 でっかいナス
**ナスの模様が4×4**にそろうと、その16マスが**でっかいナス**になり、
**その場に固定される**。固定されたマスは押しても動かず、
**そのマスを含むレーンは押せない**（崩れる心配が無い）。

タップすると**ナス攻撃**として撃ち上がる。

- 装甲を**最大値の80%**削る。
- 画面上の**雑魚と編隊を全部巻き込んで消す**。
- コンボ倍率も乗る。
- 固定したまま放置すると盤面が詰まるので、**8秒で自動発射**する。

## 編隊とピース
敵は**必ず3〜5体の編隊**で、画面外から弧を描いてギャラガのように飛んでくる。
湧く間隔は **12〜18秒に1編隊**（同時に2編隊まで）。
編隊は盤面より下、自機の広場のあたりを左右に振れながらゆっくり降りていく。
盤面は隠さない。

編隊は**横に広げず、最大3列ぶんの塊**（3体＝横一列、4体＝2×2、5体＝3+2）。
横一列にすると盤面の5列を全部ふさいでしまい、「どこから撃つか」の選択が
消えてしまうので、わざと狭くしてある。振れ幅は左右に最大 ±110px ほど。

### どの列から撃つかが変わる
**弾は雑魚に当たると、そこで止まる。** 編隊が左右に動くので、
**押せる列と押せない列が刻々と入れ替わる**。

- いま狙っているレーンに雑魚が居ると、**レーンが赤くなり**、
  その雑魚に光る枠が付いて「**弾はここで止まる**」と出る。
  自機からその雑魚までの通り道も赤くなり、押し出しの矢印は薄くなる。
- だから「左の方の列から撃つか、右の方の列から撃つか」を毎回選ぶことになる。
  編隊が左に寄っていれば右の列が通り、右に寄っていれば左の列が通る。
- ふさがっていても撃つ意味はある（雑魚を1体倒せる＝編隊全滅に近づく）。
  **盤面を押したいのか、敵を掃除したいのか**で撃つ場所が変わる、という作り。
- 左右の縦レールは盤面の行の高さを撃つので、編隊にはふさがれない。
  中央がふさがっている時の逃げ道になる。

**雑魚は弾1発で落ちる**（チャージ0段でも1発）。
**自機も雑魚もピースと同じ1マス分の大きさ**にそろえてある。

**弾は雑魚にも当たる**ので、撃ち落とさないと弾を食われてレーンに届かない。

### なぞるだけで狩れる（レーザー）
雑魚を狙って撃つのは面倒なので、**指でなぞっている間、自機が自動でレーザーを撃つ**。
いちばん近い雑魚へ水色の光線が伸びて、**シュシュシュと0.1秒おきに1体ずつ**落ちる。

- **届くのは自機から 144px（3マス）まで。** 画面の端から端まで狩れるわけではなく、
  編隊の下まで**寄っていく**必要がある。なぞっている間は届く範囲がうっすら円で出る。
- なぞっている間だけ。**その場のタップ（＝レーンを押す発射）では出ない。**
- レーンを押すのとは別枠なので、雑魚掃除のために盤面を崩さずに済む。
- 得点も編隊全滅の判定も、弾で落とした時とまったく同じ。

**編隊を全滅させると**その場で**白い枠**がピーンと飛び出し、少し見せてから
画面のいちばん下の**ストックへ吸い込まれる**（+600点）。

## ストックと入れ替え
### 縦か横かは、倒した敵で決まる
編隊は2種類の敵でできている。どちらを全滅させたかで、もらえる枠の向きが変わる。

| 倒した編隊 | もらえる枠 |
| --- | --- |
| 丸い機体（enemy1） | **横2マス**の枠 |
| 四角い機体（zako22） | **縦2マス**の枠 |

飛んでくる編隊を見れば、いま何の枠が欲しいかで狩る相手を選べる。

### ストックは画面のいちばん下。先に入った方から使う
- **3つまで**たまる。**左が「次に使う枠」**で、金色に光っている（**先入れ先出し**）。
- いっぱいの時に新しい枠が出ると、**新しい方が捨てられる**（古い方の優先を崩さない）。
- 縦の枠・横の枠が、そのまま枠の形で並ぶので、次に何が使えるか見て分かる。

### 使い方：盤面をタップ → 離すと入れ替え
ドラッグして持っていく必要は無い。**盤面をタップすると、その場に枠が出る。**

- 枠は**指より 56px 上**に出る（指で隠れないように）。指の位置には小さな白い四角が
  出て、そこから枠まで点線が伸びる。
- そのまま指を滑らせれば位置を直せる。近い2マスに**ぴたりと吸着**する。
- **指を離した所の2マスが入れ替わる**。使った枠はストックから消える。
- 自機からその場へ金色の光線が一閃し、バーンと入れ替わる。

押し出しだけでは作れない形を一手で作れるので、**大きなコンボの種**になる。

- 同じ模様どうしには使えない（変わらないので無駄打ちを防ぐ）。
- 固定された**でっかいナスの上では使えない**。
- 使えない所では枠が赤くなり「ここには使えない」と出る。離してもストックは減らない。
- **光っている塊をタップした時は撃ち上げが優先**（枠は出ない）。
  そろった塊の中を入れ替えたい場面は無いので、こちらを先にしている。

これが「編隊を全滅させる」ことのごほうび。
逃してもペナルティは無い（下へ抜けるだけ）が、枠ももらえない。

## 手応えの出し方
### コンボは「選んだ瞬間」に出る
塊をタップした瞬間にコンボが上がり、**その塊のすぐ上に `×2 COMBO` が特大でバンと出る**。
3つ目なら `×3`、4つ目なら `×4` と、**いま追加された塊の場所**に出るので、
どこで繋がったかが分かる。倍率はその弾が持ち、着弾時のダメージと得点に乗る。

### 撃ち上げはロケットのように飛ぶ
発射すると、塊の**下面のマスごとに噴射口**がつき、炎を噴いて煙を引きながら上がっていく。

### 着弾はボスの近くで大きく
- **ダメージ** … ボスのすぐ横に**特大の数字**（56px）が、0からガガガと数え上がって出る。
  同時に白い火花が散り、画面がフラッシュして揺れる。
- **得点** … その下に `+1920` のように。
- **塊の大きさ** … `4マス` と出る。3／4／5マスで得点もダメージも変わる
  （得点 = マス数² × 40 × 倍率、ダメージ = マス数² ÷ 2 × 倍率）。

ボスはエジプト神話の神々。倒すと次の面へ進み、4面目を倒すと **CONGRATULATIONS!**。

| 面 | ボス | 英字 | 装甲 | 見た目 |

| 1 | スフィンクス | SPHINX | 52 | 丸い頭巾に大きな目、寝そべった獅子身と前脚 |
| 2 | メジェド | MEDJED | 68 | 白い布から目だけ出し、下に二本の足 |

### 名前の出し方
ボスの絵のとなり（帯の左側）に、面タイトルとボス名を**カタカナと英字の併記**で出す。

```
STAGE 1 / 4
スフィンクス
SPHINX
```

英字は字間を空けて8bitらしく。下の帯には `装甲 52/52` と残りの `%`。
画面上の状態バー、ステージクリア画面、TIME UP 画面でも併記する。

参考にした絵の雰囲気（太い輪郭＋べた塗り、大きな目）に寄せて
`tools/gen_art.py` でドットに描き起こしたもの。素材そのものは使っていない。
ボスの帯は暗いので、シルエットのまわりに**淡いふち**を足して浮かせている。

- 盤面は **5×5 のまま**。大きさが変わると 4×4 の作りやすさまで変わってしまうので固定した。
- ボスは面ごとに**装甲が増え、見た目も大きくなる**（68 + 面×8 px）。足が上の帯の下端に着くように描いている。
- 雑魚は湧きが速くなり、大きい機体も出るようになる。
- 画面上の状態バーは `1／4　SPHINX` のように、何面目かとボス名を出す。

## タイムアタック（1面あたり2分）
持ち時間は **1面につき120秒**。面が変わるたびにまた2分から始まる。
**2分のゲームが4つある**という作りで、タイマーが 0 になったら、その面で **TIME UP**。

タイマーは画面の上の真ん中に大きく出し、残りで色が変わる。

| 残り | 見た目 |
| --- | --- |
| 1分より上 | いつもの金色 |
| **1分以下** | **琥珀色**にかわり、ゆっくり点滅 |
| **30秒以下** | **赤**く光って、速く点滅 |

- 撃破ボーナスは `1500×面 + その面の残り秒×20`。速く倒すほど伸びる。
- ボスを倒すと **STAGE n クリア！** の画面が出る。その面のタイムとスコア、
  残り何面かを見せ、「STAGE n+1 へ」のボタンで次の2分が始まる。
- 4面目を倒すと **CONGRATULATIONS!**。結果画面には**4面の合計タイム**と各面のタイム、
  スコア、それに**ベストタイム**（合計）が出る。
  更新したら「（更新！）」が付く。ベストタイムは `localStorage`（`xemetous_best`）に残る。
- **TIME UP** の結果画面には、どの面のどのボスを倒せなかったかとスコアが出る。
- どちらの結果画面にもロゴと **MUKKII / ALL RIGHTS RESERVED** を出し、
  「もう一度」ボタンでそのまま再挑戦できる。結果画面の間は BGM を絞り、再開で戻す。

## 操作（バーチャルパッドは使わない）
- **違うマスをタップ／なぞる** … 自機がそこへ回り込む。移動だけで弾は出ない。
  なぞっている間は**レーザーが自動で雑魚を狩る**。
- **同じマスをもう一度タップ** … 1発出る。押したままにすればためられ、離した時に出る。
- **光った塊をタップ** … 発射準備。押し出しにはならない。
- **枠があるとき盤面をタップ→離す** … その2マスが入れ替わる。
- PCは ←→↑↓ 移動、Space/Z でためて離す、X で光っている塊。

### 指で自機が隠れないように
下の広場では**自機は指のちょうど 56px 上**に立つので、広場の中に指を置いても隠れない。
左右の縦レールは自機が**盤面寄りへ横にずれる**ので、上下のずらしは入れていない。
帯に指を置けば、自機はその内側の同じ高さに立つ。

## 音
効果音のほかに**BGM**（8bitのループ、約14秒）が鳴る。音ボタンで両方まとめて切れる。
撃ち上げの瞬間には専用の発射音を鳴らしている。

iPhone は着信スイッチが「消音」だと WebAudio ごと黙ってしまうので、
無音の `<audio>` を最初のタップで一度鳴らして再生扱いにし、消音でも鳴るようにしている。

## 仮の数値
盤面の見た目 240px 固定。下の広場も 240×240（盤面の真下）。
盤面は 5×5 固定（1マス48px）。下の広場も同じ 5×5。持ち時間は1面120秒。チャージは0.3秒ごとに1段、最大3段。
移動と判定する指の移動量 14px。自機をつかむ判定 38px。発射までの待ち 1.8秒。
なぞり中のレーザーは 0.1秒に1体、射程144px、光っている時間 0.16秒。自機の持ち上げ 56px。
出した枠の持ち上げ 56px。ストックは最大3（先入れ先出し）。
コンボ窓 3.2秒。弾速 760px/秒。

## これから確かめること
チャージの段数（0.3秒刻み・最大3）が気持ちよいか。1マスずつ連打と3マスまとめ押しの使い分け。
5×5固定で 4×4 のナスを狙えるか（枠3ストックで足りるか）。
雑魚を逃した時のデメリットを何にするか（盤面を勝手にいじる以外で）。
指の置き場は足りているか（広場の中に指を置くことになる）。発射までの1.8秒の使い道。
**1面2分が厳しすぎないか／緩すぎないか**（装甲 52／68／86／108 とのつり合い）。全4面の長さ。
縦横が敵まかせで、欲しい向きが来ないもどかしさがちょうどよいか。
レーザーの射程144pxで、寄りに行く手間がちょうどよいか。編隊の湧きが12〜18秒で寂しくないか。
編隊の塊の大きさ（最大3列）と振れ幅で、撃つ列の選びがいがちょうどよいか。
