# ナスの地上絵（本線・パイロット版）— 縦スクロールシューティング

`xemetous/index.html`。これまでの試作をまとめた本線。
ゼビウスの**敵の動き・配置・テンポ**を借り、見た目と名前と音は自前で作る。

## 方針（全体）
1. **縦スクロールシューティングとして完成度を上げる。** まずゼビウスの敵の型と
   面のテンポをなぞり、そこからアレンジする。
   地上物は「ちょうどいい所に1発当てると全部そろう＝倒せる」。
   地上物には、流れてくるパズルのほかに、地上に固定されたもの（砲台など）もある。
2. **ボス戦はアンドアジェネシス風。** 雑魚のパズルより凝った盤面。
   パネポンのように作った塊を連鎖させてコンボ攻撃にする。
   倒す相手は画面上部で左右に動き、そろえた塊は上へ飛んでいくので、うまく当てる。
3. **地上弾**は、押し続けると照準が 横2 → 縦2 → 横2 … と変わり、離して発射。
   パワーアップで 3マス → 4マスと伸び、当てた範囲を順繰りに回す（向きは固定）。
4. 同じ模様を3つ以上並べたら倒せる／タップで上のボスへ攻撃、はどれも同じ。
5. 一部の地上物とボスには、**そろえると絵になるピース**がある（15パズルのように
   並べると色付きの絵が浮かぶ。大ダメージ）。ナスの地上絵もある。

## 中身
### モード
タイトルで選ぶ。選んだモードは端末に残り、Enter・Space で前に選んだ方が始まる（はじめてはノーマル）。

| モード | 言葉 → 出てくる物 | 地上絵 |
| --- | --- | --- |
| **ノーマル** | こいぬ（触れた敵が逃げる）、こねこ（少し離れた敵も逃げる）、すいか・りんご・きりん（弾をはね返す）、さかな／おさかな・おにぎり・ごりら（触れた敵をなぎ倒す）、いるか（触れた敵が逃げる） | ナス、ねこ |
| **うんち** | うんこ、うんち、ちんちん、おちんちん、ちんこ、おちんこ、おうち（弾をはね返す） | ナス、うんこ |

ひらがなの大きな文字盤なので、ノーマルモードは子どもが文字を覚えるのにも使える。
**言葉は3文字から**（マッチ3が基本）。ノーマルは「ごりら・きりん・いるか」のために ら・き・る を足した。

### 操作
移動はゼビウスのように**動かした方向・量で進む**（相対移動）。通常弾は自動。
**照準はいつも1マス**（ゼビウスと同じ）。横・縦に伸ばすのはやめた。

| | タッチ | マウス | キーボード |
| --- | --- | --- | --- |
| 移動 | どこでもなぞる | 動かす（クリックでカーソルを固定、Escで解除） | 矢印 / WASD |
| **つかむ**（照準が文字の上） | **長押し（0.22秒）**してそのままなぞる。なぞっている最中なら2本目の指で押さえる | **左右どちらかのボタンを押したまま**動かす | **N か M を押したまま**動かす |
| **地上弾**（照準が文字の上以外） | 押して離す | 左右どちらでも押して離す | N・M（Z・X）を押して離す |
| 撃ち出す | **2回すばやく押す** | 同左 | 同左 |

- 文字の上に照準が来るとそのマスが光る。押したまま動かすと、動いた先のマスと入れ替わっていく（パズドラのように）。
  **離すか、板の外に出たら終わり**。つかんでいる間は板は止まる。
- 地上弾は照準の1マスに落ちる。押してから着弾するまでは通常弾が止まる。
- 2回すばやく押すと照準に付いた物だけが飛ぶ（1回目の地上弾は出ない）。
- P の塔のカプセルは +2000点（照準は伸びない）。

### 設定（数値の調整）
上の **「設定」ボタン**（キーボードは **C**、閉じるのは C か Esc）で開く。プレイ中に開くと一時停止し、
閉じると再開する。各項目は**スライダー**と **−／＋ ボタン**で変えられるので、スマホでもPCでも使える。
変えた数値は端末（`localStorage` の `xemetous_cfg`）に残る。「初期値に戻す」あり。

| 項目 | 初期値 | 範囲 |
| --- | --- | --- |
| 自機の速さ（タッチ・マウス・キーすべての移動量にかかる） | **1.5倍** | 0.5〜3 |
| タッチ感度 | 1.3倍 | 0.5〜3 |
| マウス感度 | 1.2倍 | 0.3〜3 |
| キー移動の速さ | 300 px/秒 | 100〜600 |
| 自機の追従（大きいほど操作にぴったり付く） | 16 | 4〜40 |
| 照準の距離 | 118 px | 70〜200 |
| 空中弾の数 | 3発 | 1〜8 |
| 敵弾の量 | 1倍 | 0〜2（0で撃たない） |
| 敵弾の速さ | 150 px/秒 | 80〜260 |
| 地上弾が落ちる時間 | 0.55秒 | 0.2〜1.2 |
| スクロールの速さ | 42 px/秒 | 20〜90 |

地上弾は0.55秒かけて前方に落ち、着弾点は地面と一緒に流れる。
地上弾は1発ずつ。通常弾とは別に撃てる（ゼビウスと同じ）。

### 空の敵（ゼビウスの敵の「型」を借りたオリジナル）
| 型 | 動き | 元にした型 |
| --- | --- | --- |
| リング | 自機の方へゆるく寄ってきて、**x がそろうと引き返す**。ただし**気づくまで0.2秒遅れ、そこから慣性で切り返す**ので、引きつけて追いかければ落とせる。列の中の決まった1機だけが、切り返す時に光ってから1発撃つ | トーロイド |
| 円盤 | 降りてきてブレーキ、**止まって0.75秒光ってから**1発、加速して帰る | トーカン |
| 箱 | ふっと現れ、**光ってから**1発撃って消える | ザカート |
| 回る板 | **弾が効かない**。すき間のある壁になって降りてくる | バキュラ |
| 翼 | S字に大きくうねって通り抜ける。撃たない | ジアラ |

4機以上の編隊を全部落とすと **編隊全滅ボーナス**（100×機数）。

### 敵の弾（パズル中でも避けられる量）
- **撃つ前に必ず光る**（白い輪が点滅しながら縮む）。砲台も砲口が光る。
- **画面に出せる敵弾は2発まで**（エリアが進むと増える）。撃つ間隔も0.55秒空ける。
- **自機の後ろ側・130px以内の目の前からは撃たない**。
- 弾の速さは毎秒150px。砲台は3.6秒おき（前は2.2秒）。
- 同じ動きのボットで比べると、1エリアの敵弾は **34発 → 13発**、画面に同時に出る数は **7 → 2**。
- 設定画面の「敵弾の量」（0〜2倍、0で撃たない）「敵弾の速さ」で変えられる。

### 面（メリハリ）
ゼビウスの1面のように、**空の山場**と**地上をじっくり狙う間**を交互に置く。1エリア約70秒。

| 時間 | 区間 | 中身 |
| --- | --- | --- |
| 0〜10秒 | 導入 | 撃ってこないリングの列が左右から。引きつけて落とす練習。パズル1枚 |
| 10〜18秒 | 地上の間 | 砲台とパズル。空は撃たない翼だけ |
| 19〜29秒 | 空の山 | 円盤の二段構え、撃つリングの列、箱 |
| 30〜37秒 | 休み | 空は空っぽ。パズル2枚とPの塔をじっくり |
| 38〜47秒 | バキュラの壁 | すき間のある板の壁をくぐる。合間をリングが横切る |
| 48〜58秒 | 締めの山 | 円盤3機、翼、リングの列が左右から、箱3つ |
| 59〜70秒 | 静かに終わる | 最後のパズルとピラミッド |

### 地上物：「そろえる」と「けす」
**そろえる** … 文字（ことば）か地上絵の欠片（ピース）の板。つかんで動かして並べる。

| 言葉（左→右か上→下に読む） | 出てくる物 | 特ちょう |
| --- | --- | --- |
| うんこ | うんこ | 敵が触れるとウワーと逃げる。固くて長持ち、撃ち出すと強い |
| うんち | うんち | 臭い。少し離れた敵も逃げる |
| ちち | おっぱい | 敵の弾をボヨンとはね返す（はね返った弾は敵に当たる） |
| おちち | おっぱい（強化版） | もっと大きくて長持ち |
| ちんちん | ちんちん（ぞうさん） | 触れた敵をなぎ倒す |
| おちんちん | ちんちん（強化版） | もっと大きくて強い |

- 重なって読める時は**長い言葉が優先**（「おちんちん」の中の「ちんちん」は数えない）。
- **1列の板**（横か縦）：言葉1つ（短い言葉には余分な1文字）がばらばら。読めたら板ごと消える。
- **5×3 の大きな板**：いろいろな文字。読めた所が消えて**上から文字が落ちてきて**、続けて読めると**連鎖**。
  1回の操作でできた言葉の数が**コンボ**で、出てきた物の威力はコンボ数倍（撃ち出す時のまとめ撃ち倍率にさらに掛かる）。
- **地上絵**（うんこ・ナス）：3×3 の欠片を元の位置に戻すと、板と同じ大きさの**デカうんこ／デカナス**。
- 最初から読めてしまう板は出さない（各500枚で確認）。
- 板は降りてきたら画面の中をしばらくウロウロし（下の紫の棒が残り時間）、時間が来ると**灰色になってすばやく（毎秒360px）**画面の上へ消える（もう触れない）。
  ほかの板や砲台と重ならない高さ・向きで動く。ヒントの文字は出さない。

**けす（まとめて倒すと得）** … 横や縦に2〜4個並んだ**砲台**（撃ってくる）と**ピラミッド**（撃たない）。
決まった所で数秒止まる（画面に固定）。照準の範囲に入ったものはまとめて壊れ、2体以上で +300×体数。
**P の塔**は壊すとカプセル（照準が 3 → 4 マス）。

### 言葉ができたら（溜めてからまとめて出す）
- 言葉ができても**すぐには出てこない**。その文字が**約2.2秒光って**待つ（板の右上の輪が残り時間）。
  光っている文字はつかめず、ほかの文字を動かしてそこにぶつかると、そこでつかむのが終わる。
- 待っている間に**同じ板でほかの言葉もできたら**、それも光って待ちに加わり、時間がまた2.2秒に戻る。
- 光っている間、その言葉のパネルは**出てくる物の絵に変わる**（おにぎりなら🍙が4つ）。
- 時間が来ると**まとめて出てくる＝コンボ**。**文字の数だけ**出てくる（1つあたりの威力は1語ぶん÷文字数くらい）。威力はコンボ数倍。
  **女の子のカットイン**が出て「おちんちん・ちんこ！」のように吹き出しに出し、**声で読み上げる**。
- 5×3 の板は、出た後に空いた所へ上から文字が落ちてきて、そこでまた言葉ができると次のコンボが始まる。
- 板が時間切れで上へ消える時、光っている言葉はその場で出す。
- うんちモードに「ちんこ」を追加（ちんちんと同じ物が出る）。照準に付けられるのは4つまで（デカいのは1つで全部ぶん）。

### 声と絵
- 声は **VOICEVOX:春日部つむぎ** で作った音声ファイル（女の子の声1人）。**言葉ができた瞬間に**「おさかな！」と読み、
  まとめて出る時にコンボなら「ツーコンボ！」と続ける。声の間は効果音を小さくして聞こえやすくしている。アクセントは1語ずつ東京式に直してある（tools/gen_voice.py）。
  音声が読み込めていない時だけ端末の読み上げで代わりに読む。設定の「声」で なし／あり。
- 女の子の絵はコードで描いたちびキャラ（画像生成AIの絵も試したが、こちらの方がよいとのことで戻した。前の2倍の大きさ）。
  カットインは**画面の下**（敵も地上物もいない所）に、**言葉ができた瞬間、声と同時に**出す。待っている間に言葉が増えると吹き出しに書き足し、
  まとめて出る時にコンボなら「ツーコンボ」と続ける。
- 絵合わせがそろった時も「なす！」「こねこ！」と読む。伝説の攻撃は「なすのちじょうえ！」。
- こねこの絵合わせは地上絵ではなく、ふつうの こねこ の絵（Twemoji）。
- うんちモードからおっぱい系（ちち・おちち）を外した。うんちモードの言葉は うんこ・うんち・ちんちん・おちんちん・ちんこ。

### 生まれたキャラ（照準にくっつけて使う）
- 言葉なら**文字の数だけ**小さく生まれて、ゆっくり昇っていく。**どれか1つを照準で捕まえると、同じ言葉から
  生まれたぶんが全部集まって1体の大きなキャラ**になり、照準にくっつく（おにぎり4つ → 大きなおにぎり1体）。
  絵合わせ（ナス・こねこ・うんこ）なら最初から大きなキャラ1体。
- くっついたキャラは**敵の弾を消す・ザコを倒す・バキュラを倒せるのはこれだけ**（+500）。
  ぶつかると HP が減り（下の棒）、0 で消える。
- **生まれてから22秒**たつと「バイバーイ」とどこかへ飛んで行ってしまう（まわりの輪が残り時間、5秒前から赤く点滅）。
- **いくつでも**くっつけられる（照準のまわりに並ぶ）。くっついている間も通常弾は撃てる。
- 地上弾を**2回すばやく押す**と全部を撃ち出してボスにぶつける。飛んでいる間は時間切れにならない。
  威力は HP の減り具合と関係なし。威力＝文字1つぶん×文字の数、n 体同時なら n 倍、コンボで生まれたぶんはさらにコンボ数倍。
- キャラごとの役割の違いはまだ相談中（今はどれも同じ働きで、威力と HP だけが違う）。

### ボス：地を這う要塞（アンドアジェネシス風）
- 約64秒で「WARNING」、画面上部に八角形の要塞が降りてきて左右に動く。**体力バーは画面の上に大きく**出る。
- **通常弾も効く**（1発1）。でも**うんこの威力は桁違い**（デカうんこ1個で160、うんこ3個同時なら 40×3×3＝360）。
  左右に動くので、当たる時に要塞がそこにいるよう撃つ。
- 地上弾を中央のコアに当てると6、四隅の砲台は地上弾で壊せる（+500。撃つ前に光る）。
- 戦っている間、下の方に板がせり上がってくる（6秒おき。
  （1列のことば → 3×3 → 地上絵の順）。そろえて → 捕まえて → ためて → 真下でまとめて撃つ。空からはリングの列もときどき来る。
- 体力 700。半分を切ると速く動く。
- **体力が7割を切ると、画面いっぱい（8×5）のナスの地上絵があらわれる**。その間ほかの板は出ない（出ていた板は帰る）。
  崩れているのは隣どうしの入れ替え4か所だけ（1回ずつ直せば完成）。60秒以内にそろえると**伝説の攻撃「ナスの地上絵」**：
  「ナスの地上絵よォォッ！」と興奮した声で叫び、巨大なナスが要塞へ飛んで体力の半分以上のダメージ。
- 倒すと**ゲームクリア**（パイロット版なので1面でおしまい）。クリアすると BGM が止まってクリアのファンファーレ（魔王魂 ジングル09）が鳴り、「タイトルに戻る」だけが出る。
  ゲームオーバーでは「コンティニュー」（やられた所から残機を戻して続ける）と「タイトルに戻る」を選べる。

### 大きさ（ゼビウスのパロディなので、比率をそっくりに）
照準1マス＝文字1つ＝ **52px**（前は34px。画面の幅440pxに8マス半ほど。ゼビウスの照準と画面の比に近い）。
自機・敵・通常弾・砲台やピラミッドも同じ倍率（約1.5倍）で大きくした。自機の当たりは中心の点のまま、
敵との体当たりの判定は少し小さめにしてある。照準の距離の初期値は 150px（設定で変えられる）。
文字盤は1文字がこの大きさなので、1列の板でも幅156〜260px、5×3 の板は 260×156px と大きい。
大きくなったぶん、**そろえる板は同時に2枚まで**（3枚目は空くまで待つ）、置ける高さが無い時は画面の上で待つ。

### 画面の縦横比
画面（440×680）の縦横比は常に保つ。縦長のモニタやスマホでは上下、横長では左右に黒い帯が出る。
大きな画面ではそのぶん大きく表示する。

### 面の終わり
ボスを倒すと AREA クリア。次のエリアは少し速くなり、撃つ敵と画面の敵弾の上限が増え、要塞も固くなる。
残機3。自機の当たりは中心の白い点だけ（小さめ）。やられると2.2秒無敵で復活。

### 音
今は仮の音。BGM はデフォルトで鳴らない（BGM ボタン）。第4段で作り直す。
