# XEMETOUS BLASTER（第四案）— 飛んで、ひっくり返して、撃ち上げる

`blaster/index.html`。第三案 XEMETOUS の絵・音・ボス・撃ち上げをそのまま使い、
**操作をゼビウスそのものに寄せた**別バージョン。全4面。

## 何が違うか
第三案は「レールを走って弾でレーンを押す」だった。こちらは**普通に空を飛ぶ**。

- 自機は**画面の中を自由に飛ぶ**（なぞった所へ行く）。
- **通常弾は自動で出る**。撃つ操作はいらない。
- 盤面（砂の板）は**地上**にあって、**地上攻撃の照準**で並びをひっくり返す。

ゼビウスの「対空はオート連射、対地はブラスター」という構えを、
そのままパズルの入力にしている。

## 自機と通常弾
- 画面をなぞると、自機がそこへ飛ぶ。**自機は指の 56px 上**に立つので、
  指で自機も地上も隠れない。自機そのもの（38px以内）を押した時は動かさない。
- **通常弾は 0.16秒ごとに自動発射**。上へまっすぐ飛び、空の敵に当たる。
- 敵は**上から降りてくる**。地上（盤面）の上を飛び越えていく。

## 地上攻撃の照準
自機の**ちょうど 96px（2マス）前**に、白い照準が常に出ている。
自機が動けば照準も動く。

### 向きは「なぞり始めた側」で決まる
| なぞり始めた場所 | 照準 |
| --- | --- |
| **画面の左半分** | **横**に並んだマス |
| **画面の右半分** | **縦**に並んだマス |

なぞっている途中で左右をまたいでも向きは変わらない。**始めた側**で決まる。

### 指を離すと地上弾
- 地上弾が照準まで飛んで（0.34秒）、**その並びを丸ごとひっくり返す**。
  2マスなら入れ替え、3〜5マスなら逆順。
- **地上弾が飛んでいる間は通常弾が止まる**。撃ちっぱなしにすると空がガラ空きになる、
  というのがこのゲームの緊張。
- 地上弾は**1発ずつ**。飛んでいる間は次を撃てない。
- ひっくり返しても同じ並び（左右対称・同じ模様）の時と、
  固定されたでっかいナスの上では撃てない。照準が赤くなる。

## パワーアップカプセル
**編隊を全滅させると、その場からカプセルが落ちてくる**（+600点）。
自機で触れると取れる。**取らなくてもいい**（画面の下へ抜けていく）。

| 取った数 | 照準の長さ |
| --- | --- |
| 0 | 2マス（入れ替え） |
| 1 | **3マス** |
| 2 | **4マス** |
| 3 | **5マス**（盤面の端から端まで） |

最大まで伸びたあとのカプセルは +800点。
長いほど一手で大きく動かせるが、**狙いを外した時の被害も大きい**。

## そろえて、タップして、撃ち上げる（第三案と同じ）
同じ模様が縦か横に3つ以上そろうと輪郭が水色に光る。
**そこをタップすると確定**し、**1.8秒後**にボスへ飛んでいく。

- ダメージは **マス数²÷2**。3マスで5、4マスで8、5マスで13。
- **3.2秒以内**に次を確定させるとコンボ。倍率はダメージと得点の両方に乗る。
- **ナスが4×4**にそろうと固定され、タップで**ナス攻撃**（装甲の8割＋雑魚全滅）。
  8秒放置で自動発射。

## 全4面
第三案と同じボス。倒すと **STAGE n クリア！**、4面目で **CONGRATULATIONS!**。

| 面 | ボス | 英字 | 装甲 |
| --- | --- | --- | --- |
| 1 | スフィンクス | SPHINX | 52 |
| 2 | メジェド | MEDJED | 68 |
| 3 | バステト | BASTET | 86 |
| 4 | アヌビス | ANUBIS | 108 |

**時間制限は無い**（第三案のタイムアタックはこちらには入れていない）。
ハイスコアだけ `localStorage`（`xemetous_blaster_best`）に残る。

## 操作
- **なぞる** … 自機が飛ぶ。通常弾は自動。
- **指を離す** … 地上弾。照準の並びがひっくり返る。
- **左半分から／右半分から** なぞり始める … 照準が横／縦。
- **光った塊をタップ** … 確定。少し待って撃ち上がる。
- **カプセルに触れる** … 照準が伸びる。
- PCは ←→↑↓ 移動、Space/Z で地上弾、C で照準の縦横、X で光っている塊。

## 仮の数値
盤面（地上）240px 固定、5×5（1マス48px）、上端 y=130。
自機の飛べる範囲は y 226〜588。自機の持ち上げ 56px。自機をつかむ判定 38px。
照準は自機の 96px 前。地上弾の到達 0.34秒。通常弾は 0.16秒ごと、弾速 820px/秒。
編隊は 5〜14秒に1つ、最大3列ぶんの塊、降下 26+面×6 px/秒。
確定から発射まで 1.8秒。コンボ窓 3.2秒。

## これから確かめること
「離したら必ず撃つ」で、位置を直すだけができないのが窮屈でないか
（直したいだけの時にどうするか）。
通常弾が止まる時間 0.34秒が、緊張として効いているか短すぎないか。
照準が5マスまで伸びた時、狙いが大ざっぱになりすぎないか。
敵が地上（盤面）の上を飛ぶので、並びが読みづらくないか。
時間制限を入れるかどうか。自機がやられる要素を入れるかどうか。
