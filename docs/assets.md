# 素材について

## 出どころ
この試作の絵と音は **すべてリポジトリ内のスクリプトで生成した自作素材** です。

当初の予定では絵をフリー素材サイトから、音を
[効果音ラボ](https://soundeffect-lab.info/) から持ってくるつもりでしたが、
開発環境の外向き通信がパッケージレジストリ（pypi / npm）だけに制限されていて、
効果音ラボ・Kenney・OpenGameArt などへ到達できませんでした（CONNECT が 403）。
そのため「なければ自分で作る」方針に切り替えています。

素材は自作なので、このリポジトリのライセンスの範囲で自由に使えます。
外部サイトの素材に差し替えたくなった場合は、下の対応表の名前でファイルを
置き換えれば、そのまま読み込まれます（利用規約とクレジット表記の確認は忘れずに）。

## 絵 — `assets/img/`（`python3 tools/gen_art.py` で再生成）
1ドット＝1pxのドット絵。表示側は `image-rendering: pixelated` と整数倍拡大で、
8ビット機のような硬いドットのまま出しています。

| ファイル | 中身 |
| --- | --- |
| `ship.png` | 自機（16×16）。ゼビウスのソルバルウ風の三角翼 |
| `enemy1.png` | 1×1の敵（16×16）。回転リング型 |
| `enemy2.png` | 2×1の敵（32×16）。横長の高速機 |
| `enemy4.png` | 地上ボスの頭部（32×32）。赤いコアを持つ大型母艦 |
| `zako22.png` | 2×2の雑魚（32×32）。ボスと取り違えないよう四つ足の角ばった機体 |
| `shot.png` | 自機のショット（4×12） |
| `boom.png` | 爆発5コマ（24×24×5） |
| `glyphs.png` | 地上ピースの模様5種（24×24×5）。二条線／十字／稲妻／渦／輪 |
| `slab.png` / `slab_lit.png` | ピースの土台。通常時と成立時 |
| `sand.png` | 砂漠の地面（64×64、縦横につながる） |

模様は「砂に彫り込まれた溝」に見えるよう、影の線と反射光の線を1pxずらして
重ねています。**ピースの区別は色ではなく線の形だけ**で、土台の色は全種類同じです。

## 音 — `assets/sfx/`（`python3 tools/gen_sfx.py` で再生成）
22050Hz / 8bit / モノラルの WAV。矩形波とノイズだけで作り、
8bit に量子化してわざとざらつかせています。効果音は全部で約 120KB、BGM が約 300KB。

| ファイル | 場面 |
| --- | --- |
| `shot` / `hit` | ショット発射／敵に命中 |
| `boom_s` / `boom_l` | 小型機／大型機の撃破 |
| `pickup` | ピースをNEXTに獲得 |
| `move` | 自機のマス移動 |
| `swap` / `place` / `deny` | 地上の交換／配置／置けない |
| `match` | 成立して消去待ちに入った合図 |
| `clear` / `sq2` / `sq3` | 消去。3直線／2×2／3×3 |
| `chain` | 連鎖（再生時に `playbackRate` で音程を上げる） |
| `warn` | ボス接近の警報 |
| `bossdown` | ボス撃破 |
| `launch` | 塊を撃ち上げる瞬間 |
| `charge` | 押してためる時に段が上がる合図 |
| `bgm` | BGM（約14秒のループ） |
| `start` | ゲーム開始のジングル |

## 音が鳴らない時
iPhone は着信スイッチが「消音」だと WebAudio ごと黙る。
無音の `<audio>` を最初のタップで一度鳴らして再生扱いにすることで回避している。

## 読み込みの作法
- 画像も音も、読み込めなかった場合はコード側の描画・合成音にフォールバックします。
  `file://` で直接開くと `fetch` が通らず音がWAVから合成音に落ちるので、
  ちゃんと聴くときは HTTP で配信してください（例: `python3 -m http.server`）。
