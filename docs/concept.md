# METOPON 試作03 — 同じものをそろえる
## 基本構成
空中で敵を狙って撃ち、地上用ピースを集める。地上は自機の照準から操作するマッチパズル。
敵弾、接触ダメージ、回避、HPなし。具象的な地上絵・召喚は採用しない。

## 今回のルール
- 同じ色・記号を縦横3個以上、2×2、3×3にそろえる。斜めや2個だけでは成立しない。
- 成立したマスは2.4秒後に消える。その間も交換・配置でき、成立範囲を更新する。成立を崩すと対象から外れる。成立が全てなくなれば消去待ちを解除。
- 初回成立からの締切は追加操作で延長しない。四角を大きくする時間として使える。
- 消去は1マス30点。2×2は160点、3×3は900点追加（同時成立では最大の形を1回評価）。3.2秒以内の次の消去で連鎖倍率。
- 消去後は落下・補充し、自動成立にも消去待ちを設ける。これは本家作品のルールの再現ではなく試作用の連鎖ルール。
- 自機は1マスずつ上下左右へ移動。長入力は0.14秒ごと。敵は0.55秒ごとに下または横へステップ移動。
- 空中敵は1×1・2×1・2×2。撃破で同じ形・同じ色のピースをNEXTへ自動追加。
- B：交換は隣接2マスを入れ替え。B：配置はNEXT先頭を形ごと上書き配置。右側に次の6個と総数。
- 音はSEのみ。リズム判定は未実装。

## 操作
左パッドまたは画面ドラッグでマス移動。A長押しで射撃。Bタップで地上操作。
下のBモードボタンで交換／配置を切り替える。PCは矢印/WASD、Space/Z、X。
音切替、一時停止、リセット対応。タブ離脱で停止。

## これから確かめること
照準で地上を動かす楽しさ、消去待ちの長さ、3直線から大きい四角を作る余地、空中との行き来。
形・時間・得点は仮仕様。ソース正本はmukkii-game/metopon。
