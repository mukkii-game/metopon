# METOPON 構想と触れる試作 02

## 合意した方向
- スマートフォン優先。空中は連続的な移動と射撃、地上は格子上のパズル。
- 自機移動とA/Bの2種の攻撃で両方へ介入する。
- 空中で撃破した成果が地上用の素材になる。地上の成果は空中へ還元する。
- 小さく撃つ・消す楽しさと、大きなものを完成させるカタルシスを両立する。
- 地上絵は抽象的な回路だけでなく具象物。ナスの形を作るとナスが現れるなど、絵と結果に意味のつながりを持たせる。
- 反応中の介入による連鎖、リズムは今後育てる。厳しい音ゲーを必須にしない。

## この試作だけの仮ルール
- 7×7盤面・4種類（色と記号を併用）。固定のナスの輪郭が目標。
- 回避は廃止。敵弾・接触ダメージ・HP・ゲームオーバーなし。空中は位置を合わせて狙い撃つ遊び。
- 1×1、2×1、2×2の敵が出現。耐久は2/3/5発（仮）。撃破で同じ色・形のピースを自動獲得し、右側NEXTに先入れ先出しで蓄積。先頭6個と総数を表示。
- 自機の約150論理px上が対地照準。Bは隣接2マスを交換。モード切替でNEXTの先頭ピースを形のまま配置（既存マスを上書き）。配置前に範囲と色・記号を予告。端では全体が入るよう照準を補正。交換はストックを消費しない。
- 縦横3個以上で消去・重力補充。目標の位置を消すと、その場所に地上絵が刻まれる。
- 3.2秒以内の次の成立で連鎖倍率。消去は即時、補充後の自動連鎖は未実装。パネポン的な消去途中の介入を再現したものではなく、二層をつなぐ最小試作。
- 地上絵完成で巨大ナスが出現し空中の敵を一掃。次の絵へ。
- 召喚を見るボタンは演出確認用（完成ボーナスなし）。自然完成とは別の検証入口。
- 音は合成SEのみ。BGM・拍判定・飛行中の爆弾・可変範囲・自由な地上絵認識は未実装。
- 絵は固定のシルエットを埋める方式。自由描画やAIによる形の認識ではない。

## 操作
スマホ：左パッドまたは画面ドラッグで移動、A長押し連射、Bタップ地上操作。
PC：矢印/WASD、Space/Zで射撃、Xで地上操作。Bの交換/配置は画面ボタンで切替。
音ON/OFF、一時停止、再開始対応。タブ離脱時は停止。

## 触って判断すること
1. 同じ場所で空中と地上を重ねて読めるか。敵や弾が盤面を遮りすぎないか。
2. 自機位置から地上を狙う操作が楽しいか。画面ドラッグと左パッドのどちらが楽か。
3. 空中を撃つ理由、素材を獲得する理由、地上を完成させる理由がつながるか。
4. シルエットを埋める作業感が強くないか。形の作り方や複数の目標を後で比較する。
5. 具象物が飛び出す召喚に、次の試作を続ける魅力があるか。
